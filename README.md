# حنين مشرف
### مهندسة معلوماتية

مطوّرة متكاملة أبني تطبيقات وأنظمة حقيقية للحاسوب والهاتف والويب وشاشات التلفزيون الذكية، ولدي خبرة عملية بتطوير تطبيقات Flutter المرتبطة بقواعد بيانات Supabase.

أمتلك معرفة في الذكاء الاصطناعي بشقّيه، التعلم العميق والتعلم الآلي، وقادرة على بناء النماذج ودمجها ضمن التطبيقات والأنظمة لتتحول إلى أنظمة أو تطبيقات ذكية فعلية.

**التقنيات:** Flutter · Dart · Supabase · Python · SQL · PHP · Java · C# · TensorFlow / Keras · Scikit-learn

## أبرز المشاريع

**🔒 نظام ERP —لشركة ديلو فود (فرع منطقة الزبلطاني في دمشق)**
نظام إدارة متكامل لشركة في سوريا. مشروع خاص بعميل، الكود غير متاح للعرض العام.

**[Gluco-Vision](https://github.com/hanenmoshref5-cell/Gluco-Vision)**
تطبيق لقياس نسبة سكر الدم عبر تحليل إشارة PPG من كاميرا الهاتف، بالاعتماد على نموذج Random Forest مدرّب على بيانات حقيقية. حصل على المركز الثالث بمؤتمر شرف للذكاء الاصطناعي بدرعا، وقُدّم أيضًا كمشروع ما قبل التخرج.

**[Service-Provider_MobileApplication](https://github.com/hanenmoshref5-cell/Service-Provider_MobileApplication)**
تطبيق لطلب الخدمات مرتبط بخادم حقيقي مبني بإطار Laravel. أُنجز كمشروع نهائي من تدريب Flutter وبرمجة تطبيقات الموبايل في شركة تمكين، وحصلت بعده على شهادة توصية من الشركة.

**[screen-volume-limiter](https://github.com/hanenmoshref5-cell/screen-volume-limiter)**
نظام مكوّن من تطبيق Flutter وخدمة تعمل بالخلفية على أجهزة تلفزيون LG، للتحكم بالحد الأقصى لمستوى الصوت وحفظه تلقائيًا عند الإقلاع.
